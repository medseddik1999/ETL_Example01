# README.md — ETL_Example01## 1. ObjectifFaire évoluer le projet ETL PySpark en développant deux fonctionnalités métier indépendantes, en parallèle, sur GitHub.## 2. Répartition du travail### Développeur A — Analyse des ventes par région et produit- Regrouper les ventes par région, catégorie et sous-catégorie.- Calculer le nombre de commandes, les quantités vendues, le chiffre d'affaires et le profit.- Calculer la marge bénéficiaire.- Générer `output/sales_by_region_product.csv`.**Fichiers :** `sales_by_region.py`, `run_sales_by_region.py`, `test/test_sales_by_region.py`.### Développeur B — KPI financiers mensuels- Regrouper les ventes par mois.- Calculer le chiffre d'affaires, les remises, les coûts et les profits.- Calculer la marge, le panier moyen et l'évolution mensuelle du chiffre d'affaires.- Générer `output/monthly_financial_kpi.csv`.**Fichiers :** `monthly_kpi.py`, `run_monthly_kpi.py`, `test/test_monthly_kpi.py`.## 3. Workflow GitChaque développeur travaille sur sa propre branche.**Développeur A :**```bashgit switch maingit pull origin maingit switch -c feature/sales-by-region-productgit push -u origin feature/sales-by-region-product```**Développeur B :**```bashgit switch maingit pull origin maingit switch -c feature/monthly-financial-kpigit push -u origin feature/monthly-financial-kpi```Ne pas modifier simultanément `main.py` ou `transform.py` afin de limiter les conflits.## 4. Tests et livraisonExécuter les tests :```bashpython -m pytest test/ -v```Puis, pour chaque fonctionnalité :```bashgit add <fichiers-modifies>git commit -m "feat: add business report"git push```Ouvrir une Pull Request et faire vérifier le code avant la fusion.## 5. Critères de validation- Les calculs métier sont corrects.- Les valeurs manquantes et les divisions par zéro sont gérées.- Les tests passent.- Les deux fichiers CSV sont générés.- Le rapport existant `sales_per_city.csv` continue de fonctionner.**Résultat attendu :** trois rapports complémentaires — ventes par ville, ventes par région et produit, et KPI financiers mensuels.
